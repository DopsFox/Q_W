Smart Route Optimizer and Dispatcher

This software for delivery route optimization and dispatching was created as my qualification project in applied software engineering. The application automates logistics planning, finds the best order to visit customer addresses, and shows the created route on an interactive map using the real road network.
To find the most effective order of visiting stops, the program includes three optimization methods. The first method uses the A-star algorithm with heuristic estimations to quickly reduce the search space. The second method uses Dijkstra algorithm to find the exact sequence with the minimum total travel cost. The third method uses the Ant Colony Optimization algorithm, which copies the behavior of real ants and finds good near-optimal solutions by updating and evaporating pheromones. Each algorithm can work in four priority modes: strict priority following, completely ignoring priorities to reduce total distance, and partial priority ignoring with exponential or logistic penalty reduction based on the number of orders and cargo volume.
The software has a smart built-in geocoder that searches for coordinates using Nominatim, ArcGIS, and Photon services one by one. The module automatically cleans street names, knows old and new names of Kyiv streets, and can fall back from an exact address to a nearby street or town center if needed. To build real road routes and calculate travel time, the system uses the OSRM API. Estimated arrival time for each point is calculated automatically, taking into account driving time, unloading time for boxes, and extra parking delays.
Route point management allows the user to set the start, finish, and intermediate stops manually by address or coordinates, or import address lists from TXT, CSV, or JSON files with a selection option. The interface is built with PySide6 and includes an embedded Folium map, order tables, and calculation metrics. For easier dispatch work, there is an action history system that supports undo and redo functions.
The program also has an analytical module to compare the optimization algorithms. Using built-in tools for memory monitoring and execution time measurement, the system records peak memory usage for each method and draws clear time complexity charts depending on the number of stops.
To run the program, you need Python 3.10 or higher, an active internet connection for geocoding and routing, and the following libraries: PySide6, folium, geopy, requests, and matplotlib. The main window is launched by running the main.py file.
